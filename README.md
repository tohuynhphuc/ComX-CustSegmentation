## 2. Project Architecture & Team Division

Our BI Project is structured into 3 distinct responsibilities:

1. **ETL Team (SSIS / Visual Studio):** Extracts operational sales from SQL Server 2022 and incrementally loads into the MySQL Data Warehouse (`CompanyX_DW`).
2. **ML Team (This Python Code):** Monitors the Data Warehouse, extracts customer RFM features, trains K-Means ($K=4$), dynamically assigns business personas, and **writes the results back** into MySQL (`DimCustomerProfile`).
3. **BI Team (Power BI):** Connects directly to the enriched MySQL Data Warehouse to build interactive dashboards.

```
[SQL Server 2022] 
       │ (SSIS ETL)
       ▼
[MySQL: CompanyX_DW] ◄───► [Python ML Pipeline (K-Means + Airflow)]
       │                      - Ingestion & Scaling
       │                      - Dynamic Persona Naming
       ▼                      - Write-Back (ClusterID & Segment)
[Power BI Dashboards]
```

## 4. Key Files & How They Work

### A. `ml/dw_init.py` & `dw_init.sql`
* **Purpose:** Resets or initializes the MySQL `CompanyX_DW` database and populates all 6 dimension and fact tables from CSV files.
* **Run:** `python ml/dw_init.py`

### B. `ml/preprocess_data.py`
* **Purpose:** 
  1. Connects to `CompanyX_DW` and extracts customer RFM metrics and demographics.
  2. Deduplicates records on `CustomerKey`.
  3. Cleans invalid negative values before calculating medians to impute missing values.
  4. Applies **Log-transformation (`np.log1p`)** and **StandardScaler (Z-score)** to RFM features.

### C. `ml/clustering.py` (Core Machine Learning Script)
* **Purpose:** 
  1. Evaluates optimal clusters using **Elbow Method (Inertia)** and **Silhouette Score**.
  2. Trains K-Means with **$K=4$**.
  3. **Composite Rank Method:** Automatically scores each cluster on Monetary (points 1–4), Frequency (points 1–4), and Recency (points 1–4) to name personas dynamically without hardcoding.
  4. **Write-Back:** Updates `ClusterID` and `CustomerSegment` directly back into `DimCustomerProfile` in MySQL.
* **Run standalone:** `python ml/clustering.py`

### D. `dags/ml_customer_segmentation_dag.py` (Orchestration)
* **Purpose:** An Apache Airflow DAG configured with dynamic pathing (runs portably on any machine) and a `SqlSensor` checking if the Data Warehouse has new data before triggering the ML pipeline.

## 5. Customer Personas Generated by the Model

| Segment Name | Behavioral Profile | Strategic Business Action |
| :--- | :--- | :--- |
| 🏆 **Champions** | High Spend, High Frequency, Very Recent | VIP rewards, early access to new releases |
| 🌱 **Active** | Moderate Spend, Low Frequency, Very Recent | Cross-sell accessory bundles & loyalty onboarding |
| ⚠️ **At-Risk** | Good Historical Spend, High Recency (>120 days) | Urgent "We miss you" win-back discounts |
| 💤 **Lost / Dormant** | Lowest Spend, Inactive for longest period | Low-cost seasonal newsletters |
